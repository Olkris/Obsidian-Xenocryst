
> [!info] What's the Index ?
> The index (aka. this here file) is intended to be kept up to date with a list of markdown links to all of your files.
> 
> Why do we need this ?
> 
> Some of Xenocryst's features, like the cascading checkbox system, requires checking for the properties of ***multiple other "sub" files***, i.e. the Moments within days within weeks within months within a year.
> 
> But Obsidian Bases only gives you access to a single file's properties at once, so we can't do comparison or make checks across multiple files at once.
> Is what I would say if this clever workaround didn't exist!
> 
> If we build a list of all files, then we *can* access all files from a single function.
> 
> The index should be kept up to date automatically if you followed the [[Xenocryst initial setup steps]], and you should see a list of all of your files right below this message.
> Basically, you never have to touch this file of think about it. It just works and makes more Xenocryst features work too.
